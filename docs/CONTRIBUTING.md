# Contributing to InternMailer

Thank you for your interest in contributing!

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/InternMailer.git`
3. Install dependencies: `pip install -r requirements.txt`
4. Install Playwright browsers: `playwright install chromium`
5. Copy `.env.example` to `.env` and configure

## Development Workflow

- Create a feature branch: `git checkout -b feat/your-feature`
- Make your changes
- Run tests: `pytest tests/ -v`
- Commit with clear messages
- Push and open a Pull Request

## Code Style

- Follow PEP 8 for Python code
- Use type hints where possible
- Add docstrings to public functions
- Keep functions focused and under 50 lines

## Pull Request Process

1. Update README.md if needed
2. Ensure tests pass
3. Update requirements.txt if adding dependencies
4. Request review from maintainers

## Reporting Issues

Use GitHub Issues with these labels:
- `bug` — Something isn't working
- `enhancement` — New feature request
- `documentation` — Docs improvement
- `question` — General question
