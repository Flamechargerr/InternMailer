Features

🔍

20+ Job Sources

LinkedIn, Indeed, Glassdoor, AngelList, Greenhouse, Lever, Ashby, Workday, Remotive, WeWorkRemotely, Builtin, and more.

🤖

AI Resume Tailoring

Reads your PDF resume, extracts structured profile, and generates job-specific versions with ATS keyword optimization.

🚀

Mass Application Engine

Intelligent rate limiting (8/hr, 40/day), human-like delays, stealth browser patterns, and exponential backoff retries.

⏰

Autonomous Scheduler

Runs the full pipeline on loop: discover → tailor → apply. Respects active hours (9 AM–10 PM) and skips weekends.

📊

Web Dashboard

Real-time analytics, job queue management, application tracking, reply monitoring, and manual controls.

📧

Email Outreach

AI-generated personalized recruiter emails, inbox monitoring, reply classification, and automated follow-ups.

Quick Start

# 1. Clone & Install
git clone https://github.com/Flamechargerr/InternMailer.git
cd InternMailer
pip install -r requirements.txt
playwright install chromium

# 2. Configure
cp config/.env.example .env
# Edit .env with Gmail, Groq API key, resume path

# 3. Run
python main.py
# Open http://localhost:5050

Or run with Docker:

docker run -p 5050:5050 ghcr.io/flamechargerr/internmailer:latest

API Endpoints

# Enhanced APIs
POST /api/enhanced/discover         # 20-source job discovery
POST /api/enhanced/tailor           # AI resume tailoring
POST /api/enhanced/mass-apply       # Mass application
POST /api/enhanced/scheduler/start  # Start autonomous scheduler
GET  /api/enhanced/scheduler/analytics  # Full analytics

# Core APIs
GET  /api/stats                     # Dashboard statistics
GET  /api/jobs                      # List discovered jobs
POST /api/jobs/discover             # Trigger discovery
POST /api/jobs/apply                # Trigger application
